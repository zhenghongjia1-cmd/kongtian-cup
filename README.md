## 使用方式
1. 解压到文件夹，用浏览器打开 `index.html` 预览。
2. 注册/登录 GitHub，新建公开仓库（例如 `kongtian-cup`）。
3. 把本文件夹全部文件上传到仓库根目录。
4. 仓库 `Settings` → `Pages` → `Build and deployment` → `Deploy from a branch` → 选择 `main` 和 `/ (root)` → Save。
5. 等 GitHub Pages 发布后访问 `https://你的用户名.github.io/kongtian-cup/`。该地址只是格式示例。
6. 修改网站文件后提交到同一仓库，网站会重新部署。

## 飞书如何接入
- 创建飞书多维表格及表单视图，使用分享设置确定合法访问者。
- 在 `js/config.js` 中将 `feishuCheckinFormUrl` 替换为允许访问的表单链接。
- 如需工作人员管理入口，将 `feishuStaffAppUrl` 设置为权限受控的飞书应用入口。**不要把含个人信息的裸表公开分享。**
- 不要上传飞书 App Secret / Token / 全部人员表 / 手机号到公开 GitHub 仓库。
- 目前为「跳转链接集成」，**并非自动实时数据同步**。API同步需另行部署后端函数或可信服务。
